# Demos

Five independent portfolio demos. Each folder has its own README with a diagram, the source files and steps to run or validate it.

- [aks-helm-sre](aks-helm-sre/) - AKS + Helm delivery with SRE practices
- [banking-pipeline](banking-pipeline/) - Azure Pipelines YAML workflow for a sample Transaction API
- [terraform-hub-spoke](terraform-hub-spoke/) - Terraform hub-and-spoke environment
- [migration-plan](migration-plan/) - Windows and Linux migration plan to Azure
- [patching-lab](patching-lab/) - Patching and OS upgrade lab
